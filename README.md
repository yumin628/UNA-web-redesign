# UNA Homepage Redesign 🦁

## Overview
A conceptual redesign of the University of North Alabama (UNA) homepage. This project focuses on improving the User Experience (UX) and Human-Computer Interaction (HCI) for current students, prospective students, and alumni. By leveraging AI tools in the design and development workflow, this project proposes a more modern, intuitive, and accessible digital experience.

## Live Demo
👉 [View the Interactive Prototype](https://yumin628.github.io/UNA-web-redesign/)

## Key Features
* **Modernized UI:** A refreshed visual identity that better supports the university's message and improves readability.
* **Streamlined Content:** Organized sections for student life, campus news, and university resources to reduce cognitive load.
* **AI-Assisted Workflow:** Utilized AI tools to accelerate prototyping, layout structuring, and code generation.

## Motivation
As an Information Technology student concentrating in HCI/UX, I built this prototype to apply UX principles to a real-world platform I use every day. The goal was to demonstrate how structural design changes can significantly enhance usability and campus engagement.
